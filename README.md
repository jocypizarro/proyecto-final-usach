# Tarea 10 - Migración a Next.js

Proyecto realizado para el curso de FrontEnd de Software Libre Chile.

((La aplicación corresponde a la migración de la Tarea 9 desde React con Vite a Next.js, utilizando App Router, componentes reutilizables, manejo de estado, efectos, rutas y consumo de una API pública.))

## Funcionalidades

- Página principal del estudio creativo Wabi.
- Menú responsive.
- Slider automático con navegación manual.
- Componentes reutilizables.
- Uso de `useState`.
- Uso de `useEffect`.
- Ruta adicional `/explorar`.
- Consumo de datos desde PokeAPI.
- Estado de carga y manejo de errores.
- Navegación con `next/link`.
- Diseño responsive.

## Tecnologías utilizadas

- Next.js
- React
- JavaScript
- CSS
- PokeAPI
- Git
- GitHub
- Vercel
